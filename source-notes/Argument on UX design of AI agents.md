
These days, there are a lot of arguments and thoughts around the ai industry.

The powerful concept here is that there will be more UX decisions that will be made to reduce the GUI and make the actual 'work' that AI does invisible to the user. 

This decision was also made by recent cursor design update, where now users no longer see the code editors, but they only see the agent chat box. 

This argument brought up two main thoughts 
1. people saying they won't need a GUI that is fixed, but rather be generated by AI every single time. 
2. the detail of the work itself will no longer be visible. GUI will die, and CLI might rise again. 

Here is my thought. 
the first thought is wrong. People still need a steady fixed GUI that they can come in and expect to see. It doesn't make sense when the users are surprised every single time they come into the app. 

second thought might make some sense. But how we interact and see the CLI might have to change. 

### Suggestion 

There will be fixed GUI that everyone knows how it looks like, knows what they will see when they come back. 

This GUI will have a chat box that users can interact with nothing like other chatboxes the actual design decisions shown at [[Design approach]]
