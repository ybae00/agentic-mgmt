Based on the argument from [[Argument on UX design of AI agents]] the UI designs should look like described below. 

### Text description

The screen is a canvas. On the canvas, there is two different objects/sections that will be floating. 
1. A section on the leftside, narrow but tall box, keeping track of the task history as an item on the section. When there is a new task created, (not a following prompt from existing task) a new item will be added on the leftbar. 
2. A prompt bar that lets users prompt the AI agent. 
   
The prompt bar: On the canvas, there is a prompt bar in the middle/center of the screen. The box has a glass like effect, letting the objects behind the bar show. 

When the user prompts the AI the output is comes out in obsidian graph style node base on canvas. 

The style of the graph is same as the obsidian graph, draggable, clickable, and hoverable. 

When the user hovers on the node, it shows the description of what the task was. 

The UI is minimal, brutalist, clean. Every box has a 6px radius and a glass-morph-like effect.
